# xiangfeng50 · 天命玩家

完整静态生日游戏，无需安装依赖或编译。手机建议横屏，点击开始后启用声音。

## GitHub Pages

将本目录全部文件（包括 `.github/workflows/pages.yml`、`.nojekyll` 和 `assets`）推送到名为 `xiangfeng50` 的仓库 `main` 分支。

在仓库 Settings → Pages → Build and deployment 中将 Source 设为 GitHub Actions，再运行 Actions 中的 Deploy xiangfeng50 to GitHub Pages。成功地址为 `https://你的GitHub用户名.github.io/xiangfeng50/`。

游戏图片、脚本和字体均使用相对路径，可直接部署到上述子目录。存档保存在当前浏览器；迁移到 GitHub Pages 后，原站浏览器存档不会自动迁移。

字体许可位于 assets/FONT-LICENSE.txt。不要在本公开仓库中添加密码、密钥或个人凭据。
